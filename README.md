# Frontend - Sistema de Pesaje ⚖️

Este es el cliente web para la gestión y control de pesadas, desarrollado con React y Vite.

## 🚀 Tecnologías Utilizadas

- **React 18**: Biblioteca para la interfaz de usuario.
- **Vite**: Herramienta de construcción rápida.
- **Axios**: Cliente HTTP para comunicación con la API.
- **ESLint**: Linter para mantener la calidad del código.
- **React Select**: Para selectores de datos avanzados.

### Requisitos previos
